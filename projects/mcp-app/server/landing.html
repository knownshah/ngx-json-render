ngx-json-render MCP App

This is an MCP server, not a web page. Its endpoint is /mcp on this host (Streamable HTTP, no authentication). Add that URL as a custom connector in Claude, or as an MCP server in ChatGPT, VS Code or Cursor. It gives the model a render-ui tool that renders interactive Angular Material UI inline in the chat.
